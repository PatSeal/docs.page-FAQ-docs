## Reliable references

Prefer primary documentation when checking exact behavior:

- browser platform documentation and standards for HTML, CSS, JavaScript, and HTTP;
- official project documentation for frameworks, runtimes, and databases;
- your project's locked dependency versions and source code; and
- your own API contract, architecture decisions, and runbooks.

Search results, tutorials, and generated answers can give useful direction, but confirm security-sensitive, version-sensitive, or surprising claims in the authoritative source and a working test.

## How to ask a technical question

Include:

```text
Goal: What should happen?
Actual result: What happened instead?
Small reproduction: What is the minimum code or request that fails?
Environment: Browser, runtime, database, operating system, and relevant versions.
Evidence: Full first error, status code, request ID, and useful logs.
Attempts: What did you test, and what changed?
```

Remove secrets and personal data before sharing output. A precise question is easier to answer and often reveals the next debugging step by itself.
